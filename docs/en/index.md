# Rust Cryptopals — English Documentation

This site contains the complete documentation of the [Cryptopals Crypto Challenges](https://cryptopals.com/) solutions implemented in Rust. The challenges cover fundamental topics in modern cryptography: binary encodings, block ciphers, AES operating modes, and classic cryptanalytic attacks.

## Available sets

| Set | Theme | Challenges | Link |
|-----|-------|------------|------|
| Set 1 | Cryptography fundamentals and encodings | 1–8 | [Set 1](set1/) |
| Set 2 | Block ciphers and ECB/CBC modes | 9–16 | [Set 2](set2/) |
| Set 3 | CTR, padding oracle and statistical attacks | 17–20 | [Set 3](set3/) |
