# Set 2 — Block ciphers and ECB/CBC modes

The second set digs deeper into block ciphers, introducing PKCS#7 padding, CBC mode, and a series of practical attacks against encryption oracles: byte-at-a-time decryption, ECB cut-and-paste, padding validation, and CBC bitflipping. Each challenge demonstrates how even small pieces of information leaked by an oracle can be exploited to recover secrets.
