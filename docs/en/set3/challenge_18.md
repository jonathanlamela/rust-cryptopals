# Challenge 18 — Implement CTR, the stream cipher mode

## Theory

CTR (Counter) mode transforms AES from a block cipher into a stream cipher. The idea is simple yet powerful: instead of directly encrypting the plaintext, a sequence of counters is encrypted and the result is used as a keystream. The ciphertext is then the XOR of the plaintext and the keystream.

The structure of the counter block is: `nonce (8 bytes) || counter (8 bytes little-endian)`. For the first block, the counter is 0; for the second, 1; and so on. Since the counter (not the plaintext) is being encrypted, encryption and decryption are the same operation: XOR with the keystream. This is one of CTR's main advantages.

CTR has excellent properties: it is parallelizable in both encryption and decryption (each keystream block can be computed independently); it allows random access (block N can be decrypted without decrypting previous blocks); and it requires no padding (the keystream has the same length as the plaintext). However, the nonce must never be reused with the same key: if two messages use the same nonce, the keystream is the same, and the XOR of the two ciphertexts is the XOR of the two plaintexts — the same weakness as repeating-key XOR.

## Key concepts

- **CTR mode**: stream cipher based on AES that encrypts counters rather than the plaintext.
- **Nonce**: random value used only once to ensure keystream uniqueness.
- **Keystream**: sequence of pseudo-random bytes generated by encrypting counters, used to XOR with text.
- **`ssl_ctr_decrypt`**: `CryptoVec` method implementing CTR using the same mechanism as `ssl_ctr_encrypt`.
- **`nonce_ctr_encrypt`**: CTR implementation with explicit nonce using the `crypto` crate (aessafe).
- **Little-endian counter**: the 8-byte counter is written in little-endian format in the nonce block.

## Code walkthrough

### Overview

The challenge uses `src/cryptovec/mod.rs`, methods `ssl_ctr_decrypt` and `nonce_ctr_encrypt`. The former uses OpenSSL, the latter the `rust-crypto` crate with `aessafe::AesSafe128Encryptor`.

### Implementation

`ssl_ctr_encrypt` (also used for decryption):

```rust
fn ssl_ctr_encrypt(&self, key: &[u8], pad: Option<bool>) -> Result<Vec<u8>, JlmCryptoErrors> {
    let mut ciphertext = Vec::new();
    let mut keystream = vec![0; 16];
    for b in self.chunks(16) {
        let to_xor = keystream.to_vec().ssl_ecb_encrypt(&key, pad);
        ciphertext.extend_from_slice(&b.to_vec().xor(to_xor.unwrap()));
        for b in keystream[16 / 2..].iter_mut() {
            *b += 1;
            if *b != 0 { break; }
        }
    }
    Ok(ciphertext)
}
```

The keystream starts as 16 zero bytes. For each text block, encrypt the keystream with AES-ECB, XOR with the text block, then increment the counter in the second half of the keystream (simulating the little-endian 8-byte counter).

`nonce_ctr_encrypt` uses `aessafe` for a more explicit implementation:

```rust
fn nonce_ctr_encrypt(&self, key: &[u8], nonce: Vec<u8>) -> Result<Vec<u8>, JlmCryptoErrors> {
    let block_size = key.len();
    let encryptor = aessafe::AesSafe128Encryptor::new(&key);
    let mut result: Vec<u8> = Vec::new();
    let mut keystream = vec![0; block_size];
    for (count, block) in self.chunks(block_size).enumerate() {
        let mut nonce_count = Vec::new();
        nonce_count.extend_from_slice(&nonce[..]);
        if let Ok(_) = nonce_count.write_u64::<LittleEndian>(count as u64) {
            encryptor.encrypt_block(&nonce_count[..], &mut keystream[..]);
            let b1 = &keystream[0..block.len()];
            let x_result = b1.to_vec().xor(block.to_vec());
            result.extend_from_slice(&x_result[..]);
        } else {
            return Err(JlmCryptoErrors::FailedAesCtrEncrypt);
        }
    }
    Ok(result)
}
```

### The test

```rust
#[test]
pub fn challenge_18() {
    let ciphertext = Base64::from_string(String::from(
        "L77na/nrFsKvynd6HzOoG7GHTLXsTVu9qvY/2syLXzhPweyyMTJULu/6/kXX0KSvoOLSFQ==",
    ));
    let cleartext = ciphertext.to_bytes().unwrap()
        .ssl_ctr_decrypt(b"YELLOW SUBMARINE", Some(true)).unwrap();
    let result = String::from_utf8_lossy(&cleartext);
    assert_eq!(result, "Yo, VIP Let's kick it Ice, Ice, baby Ice, Ice, baby ")
}
```

Decrypts a Base64 ciphertext with AES-CTR and verifies the recovered text.
