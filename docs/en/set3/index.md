# Set 3 — CTR, padding oracle and statistical attacks

The third set introduces AES CTR (Counter) mode, a stream cipher built on top of AES-ECB, and the celebrated CBC padding oracle attack. The final challenges show how CTR encryption with a fixed nonce is vulnerable to the same statistical attacks used against repeating-key XOR.
