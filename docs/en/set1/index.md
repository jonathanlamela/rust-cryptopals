# Set 1 — Cryptography fundamentals and encodings

The first set introduces the fundamental building blocks of cryptography: binary encodings (hex, Base64), XOR operations, letter frequency analysis, and first approaches to block ciphers with AES in ECB mode. These challenges build the tools and intuitions required for all subsequent sets.
