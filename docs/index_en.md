# Rust Cryptopals — Bilingual Documentation IT/EN

Welcome to the documentation for the [Cryptopals Crypto Challenges](https://cryptopals.com/) solutions implemented in Rust. This project tackles all 20 challenges from the first three sets, exploring classical cryptography, block cipher attacks, encryption modes, and real-world vulnerabilities. Documentation is available in Italian and English.

## Available sets

| Set | Theme | Challenges | IT | EN |
|-----|-------|------------|----|----|
| Set 1 | Basics: encodings, XOR, statistical attacks, AES-ECB | 1–8 | [Set 1 IT](/set1/it/) | [Set 1 EN](/set1/en/) |
| Set 2 | Block ciphers: padding, CBC, oracle attacks, ECB cut-and-paste | 9–16 | [Set 2 IT](/set2/it/) | [Set 2 EN](/set2/en/) |
| Set 3 | Advanced attacks: padding oracle, CTR, keystream reuse | 17–20 | [Set 3 IT](/set3/it/) | [Set 3 EN](/set3/en/) |
