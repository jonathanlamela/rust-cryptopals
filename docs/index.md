# Rust Cryptopals — Documentazione bilingue IT/EN

Benvenuto nella documentazione delle soluzioni alle [Cryptopals Crypto Challenges](https://cryptopals.com/) implementate in Rust. Questo progetto affronta le 20 sfide dei primi tre set, esplorando crittografia classica, attacchi a cifrari a blocchi, modalità di cifratura e vulnerabilità pratiche. La documentazione è disponibile in italiano e in inglese.

## Set disponibili

| Set | Tema | Sfide | IT | EN |
|-----|------|-------|----|----|
| Set 1 | Fondamenti: codifiche, XOR, attacchi statistici, AES-ECB | 1–8 | [Set 1 IT](set1/it/) | [Set 1 EN](set1/en/) |
| Set 2 | Cifrari a blocchi: padding, CBC, oracle attacks, ECB cut-and-paste | 9–16 | [Set 2 IT](set2/it/) | [Set 2 EN](set2/en/) |
| Set 3 | Attacchi avanzati: padding oracle, CTR, keystream reuse | 17–20 | [Set 3 IT](set3/it/) | [Set 3 EN](set3/en/) |
