# Rust Cryptopals — Documentazione Italiana

Questo sito raccoglie la documentazione completa delle soluzioni alle [Cryptopals Crypto Challenges](https://cryptopals.com/) implementate in Rust. Le sfide coprono argomenti fondamentali della crittografia moderna: codifiche binarie, cifrari a blocchi, modalità operative AES e attacchi crittanalitici classici.
