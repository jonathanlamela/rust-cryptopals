# Set 3 — CTR, padding oracle e attacchi statistici

Il terzo set introduce la modalità CTR (Counter) di AES, un cifrario a flusso costruito sopra AES-ECB, e il celebre attacco "CBC padding oracle". Le ultime sfide mostrano come cifrature CTR con nonce fisso siano vulnerabili agli stessi attacchi statistici usati contro XOR a chiave ripetuta.
