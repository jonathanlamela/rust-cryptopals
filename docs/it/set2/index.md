# Set 2 — Cifrari a blocchi e modalità ECB/CBC

Il secondo set approfondisce i cifrari a blocchi, introducendo il padding PKCS#7, la modalità CBC e una serie di attacchi pratici contro oracoli di cifratura: byte-at-a-time decryption, ECB cut-and-paste, convalida del padding e CBC bitflipping. Ogni sfida dimostra come anche piccole informazioni trapelate da un oracolo possano essere sfruttate per recuperare segreti.
