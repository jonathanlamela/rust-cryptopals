# Set 1 — Fondamenti di crittografia e codifiche

Il primo set introduce i mattoni fondamentali della crittografia: codifiche binarie (hex, Base64), operazioni XOR, analisi della frequenza delle lettere e i primi approcci ai cifrari a blocchi con AES in modalità ECB. Queste sfide costruiscono gli strumenti e le intuizioni necessarie per tutti i set successivi.
