# Set 1 — Cryptography Basics

The first Cryptopals set introduces applied cryptography fundamentals: encoding conversions, XOR operations, frequency analysis, and AES in ECB mode. The challenges progress from simple binary data manipulation exercises to breaking real cryptographic schemes, building the technical foundation needed for the subsequent sets.
