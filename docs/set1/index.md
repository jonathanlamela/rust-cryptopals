# Set 1 — Fondamenti della crittografia

Il primo set di sfide Cryptopals introduce le basi della crittografia applicata: conversioni di codifica, operazioni XOR, analisi delle frequenze e il cifrario AES in modalità ECB. Le sfide partono da semplici esercizi di manipolazione dei dati binari per arrivare alla rottura di schemi crittografici reali, costruendo la base tecnica necessaria per i set successivi.
